# Бинарное дерево поиска и его вырождение


## Ход работы

В бинарное дерево поиска последовательно добавляются артикулы от 1 до 20.

Так как артикулы уже отсортированы по возрастанию, каждый следующий элемент добавляется в правое поддерево предыдущего элемента.

В результате дерево вырождается в линейную структуру:

```text
Вырожденное бинарное дерево поиска:

1
 \
  2
   \
    3
     \
      4
       \
        5
         \
          ...
           \
            20
```
Глубина дерева составляет 20.

Для проверки выполняется поиск артикула 20.

## Результат

Для эксперимента используется 20 позиций.

Количество позиций: 20

Глубина дерева: 20

Искомый артикул: 20

Цена: 550.0

Количество сравнений: 20

Время поиска: 22600 нс

## Сложность

Сложность поиска: O(n), так как вырожденное бинарное дерево поиска превращается в линейную структуру.
