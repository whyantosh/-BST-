# PriceTree

Реализовано бинарное дерево поиска для хранения артикулов и цен.

Методы:
- `insert()` — добавление товара;
- `findMinPrice()` — поиск минимальной цены;
- `inOrderTraversal()` — вывод товаров по порядку.

## Результат

```text
Артикул: A100
Минимальная цена: 450.0 руб.
Время поиска: 62400 нс
```

Сложность поиска: `O(n)`.
